### Summary of systematic weaknesses

1. **Retrieval bias** (T02, T04-hi): SerpApi Scholar ranking favours citation count and recency; contradicting RCTs may not appear in top-10 results.
2. **Surface-level stance matching** (T03): LLM reads snippet phrasing; null-result papers often describe the outcome without a clear negative signal in the abstract opening.
3. **Hinglish query drift** (T04-hi, T07-hi): Translating a claim changes the keyword set, which can shift which papers Scholar returns — causing different verdicts for the same underlying claim.
4. **Preclinical classification gap** (T10): When snippets don't contain keywords like "animal", "murine", or "in vitro", the rule-based classifier cannot distinguish preclinical from clinical studies.
