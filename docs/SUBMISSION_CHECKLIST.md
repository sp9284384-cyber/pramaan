# Submission checklist

- [ ] Deadline confirmed (site Timeline section / email the hackathon contact). Submit at least a day early.
- [ ] Both API keys regenerated if they were ever pasted into a doc, chat or commit.
- [ ] `git status` shows no `.env`, `.cache/`, or real config file. Search the repo for key strings.
- [ ] `python -m unittest discover -s tests` prints OK.
- [ ] One live run of `pramaan --check "turmeric lowers blood sugar"` works with your keys.
- [ ] `python evaluation/run_eval.py run` done; label at least ~60 rows of `label_sheet.csv`; `score` done.
- [ ] RESULTS.md contains real numbers and at least one real failure case.
- [ ] README says what is built vs planned, honestly.
- [ ] AI tools used (Claude, Gemini) disclosed in the submission form.
- [ ] Public GitHub repo opens in a private/incognito window.
- [ ] Demo video (< 3 min, runs locally) opens in a private/incognito window.
- [ ] Track chosen: Open-Source Integrations.
